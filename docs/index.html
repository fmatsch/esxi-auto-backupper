ESXi Auto Backupper

Sichert laufende VMs von einem ESXi-Host auf einen anderen – automatisch und regelmäßig. Der Ersatz für den manuellen Weg über den VMware vCenter Converter.

⬇ Für Windows herunterladen Quellcode auf GitHub
Windows 10/11 · ESXi 7.0 und 8.0 · kostenlos, MIT-Lizenz

So funktioniert ein Backup

  1. SnapshotDie VM läuft weiter, ihre Disks werden eingefroren.
  2. KopierenDie Dateien laufen durch den PC auf den Ziel-Datastore.
  3. RegistrierenDie Kopie erscheint ausgeschaltet auf dem Ziel-Host – mit deinem Hardware-Profil.
  4. AufräumenSnapshot weg, alte Backups nach deiner Aufbewahrungsregel gelöscht.

Funktionen

Quelle links, Ziel rechts

Hosts verbinden, VM und Datastore anklicken, Job anlegen. Mehr nicht.

Hardware-Profil

CPU, RAM, Netzwerk-Zuordnung und neue MAC/UUID einmal festlegen – gilt für alle künftigen Jobs.

Zeitpläne

Manuell, alle N Stunden, täglich oder wöchentlich – in der App oder über den Windows-Taskplaner.

Auch ohne Lizenz

Bei der kostenlosen ESXi-Lizenz (API read-only) weicht die App automatisch auf SSH aus.

Aufbewahrung

Die letzten N Backups bleiben, ältere werden gelöscht. Laufende VMs fasst die App nie an.

Sicher aufgeräumt

Bei Fehlern verschwinden Snapshot und halbfertiger Zielordner. Passwörter liegen im Windows-Credential-Manager.

Gut zu wissen

Bitte zuerst mit einer Test-VM ausprobieren. Die App ist durch Tests mit simulierten Hosts abgesichert, aber noch nicht breit an echter Hardware erprobt. Ein Backup ist erst dann eines, wenn die Wiederherstellung geklappt hat.

  • Volle Disk-Größe: Auch Thin-Disks werden in voller provisionierter Größe übertragen (wie beim Converter). Die Dauer richtet sich nach Disk-Größe und Netzwerk.
  • SmartScreen: Die Exe ist nicht code-signiert, Windows warnt beim ersten Start. Sie wird bei jedem Release öffentlich auf GitHub aus dem Quellcode gebaut; Prüfsummen liegen bei.
  • Zertifikate: ESXi nutzt meist selbstsignierte Zertifikate, die App akzeptiert sie. Nur in vertrauenswürdigen Netzen einsetzen.
  • Nicht unterstützt: Disks außerhalb des VM-Ordners (andere Datastores, RDM).
